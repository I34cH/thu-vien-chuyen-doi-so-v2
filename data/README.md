# data/

Thư mục chứa dữ liệu gốc. **File Excel danh mục không được đưa lên repo**, vì có họ tên thật của tác giả luận văn, khóa luận.

Muốn chạy dự án, đặt file sau vào thư mục này (xin từ nhóm hoặc thư viện khoa):

```
data/[Bản chuẩn] DANH MỤC TƯ LIỆU KHOA.xlsx
```

Sau đó chạy `backend/.venv/Scripts/python -m pipeline.reset` từ thư mục gốc (xem README.md).
